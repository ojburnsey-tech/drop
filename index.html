    Share sheet shortcuts

    Add “Send to Chromebook” and “Open on Chromebook” to your iPhone's Share menu with the Shortcuts app. These two addresses are what the shortcuts post to.

    Send files
    Open links
    How to build the shortcuts
    1. Open Shortcuts, tap +, name it Send to Chromebook.
    2. Tap the ⓘ button, turn on Show in Share Sheet, and set it to receive Images, Files, PDFs and Media.
    3. Add Repeat with Each and pick Shortcut Input.
    4. Inside it, add Get Contents of URL. Paste the Send files address, then straight after filename= add the Repeat Item variable, tap it and choose Name. Type a full stop, then add Repeat Item again and choose File Extension.
    5. Open Show More on that action. Set Method to POST and Request Body to File, then pick Repeat Item.
    6. Make a second shortcut called Open on Chromebook, receiving URLs and Safari web pages. Add Get Contents of URL with the Open links address, Method POST, Request Body File set to Shortcut Input.
